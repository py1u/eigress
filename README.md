# eigress

The Eigress project focuses on building a dashboard analytics platform to ingest and process data from Atlassian developer API tools: Jira and Confluence in real-time. This enables immediate insights into user behavior, product usage, and key performance metrics, helping businesses make informed decisions and improve product development. Eigress focuses on generating real time data visualizations that provide immediate KPI metrics and allow project managers and software teams to monitor their team progress.
